# Security

Jarvis can act on a PC (open apps, send messages, read mail, run commands in Power mode), so security problems matter.

**Report a vulnerability privately** through GitHub: *Security* tab, *Report a vulnerability* on this repository. Please include what you did, what happened, and the Jarvis version. Do not post details in a public issue until it is fixed.

Things we especially want to hear about: a way for text from an email, web page, file name or notification to make Jarvis do something without a real click, a way to read Jarvis's stored keys or sign-ins, a way around the confirmation box, or a path outside the allowed folders in the file tools.

This is a one-person early project: expect an answer within a week, not within hours.
